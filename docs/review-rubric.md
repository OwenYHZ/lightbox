# 设备还原 · 审核清单（review-rubric）

审核员只做一件事：**把照片与实现逐项对齐**，产出可执行的返工清单。不要夸、不要泛泛而谈。

## 工作方式
1. 先看该设备**全部照片**（read_image，每张都看），记下：正/背/侧/顶/底，各面有哪些零件，相对位置与比例。
2. 再看实现：SVG（渲染图或代码）、3D（详情页截图或 `/tools/device-compare.html?d=<id>`）。
3. 逐项填表，每项给出：**照片依据（文件名 + 画面位置）**、**当前实现**、**判定**、**改法**。
4. 判定只有三档：`P0 必须改` / `P1 应改` / `P2 可选`。
5. 不通过就写明"第 N 轮 · 不通过"，并列出剩余 P0/P1。

## 必查项
| # | 项目 | 判据 |
| --- | --- | --- |
| 1 | 视角一致性 | SVG 是否混用正面/侧面/透视；一件设备只能一种视角 |
| 2 | 主体比例 | 宽:高:深 与照片量取值误差 ≤ 5% |
| 3 | 分件比例 | 镜头直径/机身宽度、顶条高度/机高、拨盘直径/机宽等 |
| 4 | 颜色 | 黑/银/灰是否与实物一致；有没有把银色画成蓝灰；有没有用 accent 乱涂普通按钮 |
| 5 | 材质 | 玻璃是否 `glassClear` 且真的通透；金属是否有反射层次 |
| 6 | 文字 | 是否至少有品牌/型号文字；位置、大小、朝向是否与照片一致 |
| 7 | 结构件位置 | 热靴左右、取景器排布、拨盘位置、卡口朝向 |
| 8 | 细节完整性 | 照片上可辨认特征是否漏做（≥6 个） |
| 9 | 过渡/瑕疵 | 穿模、浮空、共面闪烁、悬空线、乱入的几何（如傻瓜机上的齿轮） |
| 10 | 画风统一 | 与另外两件并排时线宽/留白/强调色用量是否同一水准 |

## 用户已明确指出的问题（必须逐条核实并解决）
1. **ZA12**：上下比例不对；颜色不对（应为黑身 + 银饰板）；没有文字；玻璃/灯面不透。
2. **45mm**：前玉是黑的，不透明。
3. **BM-21**：正面没有任何装饰与文字；取景器那一排建模混乱；**给傻瓜机镜筒加了齿轮（滚花）——必须删除**。
4. **BM-21 矢量**：正面右侧弧线的凹凸方向反了（对照照片核实是外凸还是内收）；顶部按钮的配色乱画。
5. **45mm 矢量**：透视混用（侧面轮廓 + 正面椭圆），必须改成单一视角。
6. **ZA12 矢量**：热靴应在**左下**，画到了右下。

## 输出
写入 `docs/reviews/<device>/r<N>.md`：
- 结论（通过 / 不通过）
- 表格（见上）
- 给作者的最小修改清单（按优先级，尽量具体到数值与坐标）
- 一句话总结"离照片还差什么"
