## 4. 残余差异（我在本轮之后仍看得见）

1. **镜头前窗对角分缝没读出来**：BarrierSlit 已建（13.2×1.0、抬 0.06–0.24、#0a0a0c），但特写里仍是均匀板面 —— 怀疑被 LensWell 实体（Ø15.3，y −15.3..−13.9）在深度上覆盖，下版把分缝改成"在盖板面上刻槽"（用布尔或把缝做成盖板网格的一部分）。
2. **取景窗/AF 窗的玻璃与介质层次**仍是"一片暗玻璃"，照片是"亮玻璃 + 塑料壳 + 内部亮块"。
3. **官方图的俯视透视**导致正交渲染的机身"更高"（0.63 vs 视觉 0.55）、竖向特征位置整体差 3–8 mm；这是投影差，不是模型差，已在 §2.1-F4 标注。
4. **字形**：Konica / big mini / 顶面三行用 Arial Bold + Verdana Bold 按实测外框压缩拟合，笔画与真实字标仍有 5–10% 差异（观感）。
5. 侧面件细化（三节铰链分节、OPEN◁ 丝印）、螺丝 collar、电池门凹井（0.5）未做。
