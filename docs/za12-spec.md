# ZENIKO ZA12 · 实物量测规格书（mm 级，供 Blender 建模）

> 依据：`realDevicePhotos/ZENIKO ZA12/` 8 张实拍（4096×3072）。
> 基准：热靴插脚脚宽 **19.0 mm**（ISO 518 标准值，题设给定）。
> 量测方式：headless 浏览器/Pillow 读原图像素 → 灰度梯度亚像素边缘检测 + 连通域 + 圆弧拟合（脚本：`.tmp/za12/`，未改动 `src/`）。
> 坐标约定：**X** 向右（正向看机身），**Y** 向上，**Z** 由正面指向背面。原点 = 正面的左下角（X=0 左边缘，Y=0 机身底面，Z=0 正面）。
> 所有 px→mm 换算率与原始像素值见 §8（可复核）。

## 1. 比例基准与标定

### 1.1 基准链条

| 照片 | 用途 | 标定依据 | 换算率 k (mm/px) |
|---|---|---|---|
| 222229 正面 | **主标定**：W / H / 正面全部特征 | 热靴脚板宽度 = 512 px ↔ 19.0 mm | **0.0371** |
| 222234 底面 | D / 热靴位置与脚长 | 热靴脚板宽 450 px ↔ 19.0 mm | 0.0422 |
| 222217 顶面 | 顶板 / 拨盘 / ZENIKO | 顶板宽 1638 px ↔ 49.5 mm（由主标定推 W 后反算） | 0.0304（深度方向另有 0.88 投影压缩系数） |
| 222242 背面 | 背面板面特征 | 机身宽 1516 px ↔ 55.6 mm | 0.0367 |
| 222248 右面 | USB-C、右面比例 | 黑底带高 107 px ↔ 3.9 mm | 0.0365 |
| 222256 左面 | 左面、分模线 | 同上 | 0.0365 |

### 1.2 热靴脚宽的两处独立量测（自洽性验证）

| 照片 | 脚板像素跨度 | 说明 |
|---|---|---|
| 222234 底面（正对） | 亮边 y=1437 行，x 1342→1760 = **418 px**；含倒角外轮廓 ≈ **450 px** | 脚板顶面外轮廓 |
| 222229 正面（侧对） | y=2120 行，黑块 1498→1973 = **475 px**（受手指阴影限制，误差 ±25） | 与底面同物 |
| 222242 背面 | 黑块 1790→2380 = 590 px（k=0.0367 → 21.7 mm，含安装座） | 仅作旁证 |

取底面 450 px ↔ 19.0 mm 作基准；此时正面 512 px ↔ 19.0 mm，两张照片的尺度比为 1.14（拍摄距离不同，正常）。
**由此得 W = 1500 px × 0.0371 = 55.6 mm**，与官方 55 mm 差 1.1%，故认定标定有效。

### 1.3 误差带

| 类别 | 误差 | 原因 |
|---|---|---|
| W、正面 X 向尺寸 | ±0.4 mm | 边缘锐利、正视近垂直 |
| 正面 Y 向尺寸（窗高、带高） | ±0.5 mm | 拍摄仰角 6–10°，垂直投影压缩 <2% |
| D 及前后向尺寸 | ±1.5 mm | 仅底面/侧面可见，底面俯仰使 D 压缩约 4%（已按 45.0→46.5 修正） |
| 顶面深度向尺寸 | ±2.0 mm | 222217 为斜俯拍，深度方向投影压缩系数 0.88 |
| 拨盘圆心坐标 | ±1.0 mm | 滚花 + 刻度数字干扰弧拟合 |
