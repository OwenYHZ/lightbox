# 设备矢量图 / 三维模型 统一风格契约（v2 · 严格版）

> 三件真实设备：Konica Big Mini BM-21、OLYMPUS M.ZUIKO 45mm f/1.8、ZENIKO ZA12。
> v1 的产出被用户指出多处硬伤（玻璃不通透、无文字、比例不对、视角混用、颜色乱涂）。
> v2 把这些变成**可审核的硬规则**，违反即打回。

## 一、SVG 封面（480 × 360）

### 1. 只允许一种视角
- **正面视图**：只画正面轮廓与正面可见的零件，**不得**画侧面厚度、椭圆透视、斜视。
- **侧面视图**：只画侧面轮廓，**不得**画前端面椭圆/开口。
- 一件设备在卡片与所有场景里，视角必须固定为同一种。三件统一用**正面视图**（镜头也画正面：同心圆 + 环形滚花 + 环形铭文）。

### 2. 比例必须来自照片
- 从照片量取主体宽高比，写在函数注释里；主体在 480 宽画布上占 **260–300**（横向）或高度 **200–240**（纵向）。
- 镜头这类圆形主体，直径占画布 240–270。

### 3. 颜色只允许三类语义
- `line`：所有结构线与深色件轮廓。
- `accent` / `accent-fill`：**只**用于实物上的强调色（红点、金/银装饰环、品牌色条）。**不得**拿来给普通按钮、拨盘、窗框上色。
- `text`：文字与点阵。
- 深色块（快门盖、握把、闪光窗）用 `fill="none"` + 密集排线（`stroke-opacity="0.12"`，间距 3–4px）表示，不用大面积实心。

### 4. 线宽 / 透明度三档
`1.5 / 0.58` · `1.2 / 0.38` · `1.0 / 0.22`。不要再出现第四种。

### 5. 文字
- 环形铭文：**矢量图可读优先**（底部字翻转成正读），**三维严格按实物径向排布**。
- 每件至少 1 处**与照片一致的型号文字**（BM-21: `Konica` + `big mini`；45mm: `45mm 1:1.8`；ZA12: `ZENIKO`）。
- 字号 7–9px，**水平排布**；不要沿圆周写长串（缩略图必糊）。环形铭文用两道弧线 + 极短标签示意即可。

### 6. 方位必须与照片一致
- 左右、上下、热靴位置、按钮位置，逐项对照照片。写注释注明"左侧/右侧"。

## 二、three.js 模型

### 1. 玻璃（P0）
- 前玉、灯罩、取景窗等**透明件必须用 `materials.glassClear`**（transparent + 高清漆 + 环境反射），**禁止**用 `glass`（深色镀膜）冒充前玉，禁止黑色实心球。
- 需要深色镀膜时才用 `glass`（例如快门闭合后的镜筒内部）。

### 2. 颜色（P0）
- 双色机身（黑身 + 银饰板）必须用 `materials.silver`（中性亮银）+ `materials.rubber`/`dark`（黑）。
- 不要用受 `tone` 影响的 `plate` 充当"银色"，否则石墨 tone 会把银画成蓝灰。

### 3. 文字（P0）
- 至少 1 处，**总数 ≤ 5 处**（以实物正面文字数量为准），用 helpers.label(text, opts)（CanvasTexture 生成，无需字体文件）。
- 字高 0.05–0.09；正面文字贴在 z = 表面 + 0.003 处，不要穿模；颜色与实物一致（银面用深色字，黑面用浅色字）。

### 4. 比例（P0）
- 按照片量取 宽:高:深，误差 ≤ 5%，把量到的数值写在注释里。
- 不要给不存在的结构加细节：**BM-21 的镜筒是光滑金属环，禁止 `knurlRing`**；滚花只用于真实有滚花的部件。

### 5. 细节（P1）
- 照片上可辨认的特征至少做 6 个（取景器、闪光窗、AF 窗、快门盖、品牌字、按钮/拨盘、热靴、卡口、红点…）。
- 该有的一排控件（如 BM-21 顶部）要按"从左到右"的次序排布，间距按比例，不要挤在一起。

## 三、验收
- 审核员按 `docs/review-rubric.md` 出表，P0 必须清零，P1 ≤ 2 且说明理由，才算通过。
- 通过后内容冻结，任何人不得再改这两个文件，除非用户提出新要求。
