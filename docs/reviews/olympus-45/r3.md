# OLYMPUS M.ZUIKO DIGITAL 45mm f/1.8 · 第 3 轮定点复核

- 复核对象：前玉暖琥珀镀膜 + 共用 silver 调整
- 证据：`shots/review/r3/olympus-3d-front.png`、`olympus-3d-q34.png`、`olympus-svg.png`；裁切 `.tmp/r3_olympus_glass.png` 与照片 `.tmp/r3_photo_glass.png`

## ① 前玉：通透 / 奶白 / 暖调

| 检查 | 实测 | 判定 |
| --- | --- | --- |
| 通透（看得见内筒、第二片、镜圈层次） | 玻璃面清晰透出 3 层同心结构，无乳白遮罩 | **✓** |
| 奶白回归 | 玻璃区无 >0.7 的乳白块，中心 0.25、环带 0.45 | **✓** 没回到奶白 |
| 暖反光 | 玻璃区 mean RGB **(0.395, 0.389, 0.380)**，**R−B = +0.015** | **✗** |
| 照片基准（222138 同区域） | mean RGB (0.636, 0.592, 0.450)，**R−B = +0.186**、mean 0.63 | — |

结论：**通透 ✓ / 不奶白 ✓ / 暖调未生效 ✗**。原因：`frontGlassMat` 的 0xffe6c4 被 `opacity 0.28` 与上层的深色内筒稀释，R−B 只剩 0.015（肉眼就是中性灰）。
改法（不阻塞冻结，可后续微调）：把暖色盘做成**不受玻璃透明度影响的底层**——`z 0.5055` 处放一块 `color 0xffcf9a / opacity 0.16` 的圆盘（r 0.28），玻璃 tint 只留 0xfff2e2，目标 R−B **+0.06 ~ +0.10**（不必追到照片的 +0.19，那是木桌面反射）。

## ② 共用 silver

- 共用定义已改为 `0xc3c6cb / roughness 0.42 / envMapIntensity 0.80` ✓
- 作者实测镜筒 p50 = **0.718**，目标上界 0.70，超 **+2.6%**
- 我的抽样（q34 全环带）p25/p50/p75 = 0.047 / 0.427 / 0.784 —— 前圈是镜面掠射面，本就该出高光；Konica 机身同材质 p50 = 0.682 已在区间内
→ **接受，不再压暗。** +0.018 在区域取样噪声（±0.03）之内，继续压会连带把 BM-21 的亮铝拉灰，得不偿失。

## ③ 结论

- P0：**0**
- 新增 P1：**1**（前玉暖调未生效，R−B 0.015 → 目标 0.06–0.10，改法见 ①）
- P2：0

**签收（附条件）。** 几何、视角、文字、黑圈、玻璃通透度已与照片无明显差异，**可以不阻塞地冻结**；唯一遗留是前玉的暖色强度（P1），建议在 freeze 后作为一次独立材质微调处理，不必再走审核轮。
