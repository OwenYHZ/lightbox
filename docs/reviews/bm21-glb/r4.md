## 1. P0-A 腰线的**根因**（这次定位到材质边界，不是倒角）

- 你 v15 把倒角 3.4→1.2、外扩 0.2→0.05、并加了 0.65×0.14 的 V 槽，但**可见的黑/香槟分界一点没动**（v14 20.1 → v15 20.2）。
- 原因：`Grip` 是"正面轮廓沿 Y 挤出"的实体，**它的正面前轮廓本身仍是一条 x≈20.2 的直线**（bbox X0.5–23.8 只在顶部张开）；V 槽刻在黑色内部，不改变材质边界。所以无论倒角多小，黑/香槟分界都在 20.2。
- 唯一有效的改法：**把 Grip 实体的正面前轮廓按缝线表做出来**（不是"直线轮廓 + 槽"）：
  Ztop 0:22.9 / 2:21.6 / 6:20.4 / 10:19.3 / 14:18.5 / 18:17.7 / 22:17.3 / **26–38:17.1** / 42:17.5 / 46:18.1 / 50:18.9 / 54:19.9 / 58:20.9 / 63:21.5（你已有的表），**让 Grip 的边界曲线 = 这条表**，Shell 的开口跟着这条曲线切；
- 验收：我按同一口径复测，**至少一行 ≤18.2**（目标 17.8 @Ztop30–38）。
