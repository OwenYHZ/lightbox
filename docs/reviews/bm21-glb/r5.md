## 3. 口径记录（写给后来者）

1. **坐标**：模型导出为 Y-up（x 0→100 握把端为 0 / y 0→63 高 / z 0→32 背→前）；量测书是 Z-top（Z 从顶边向下）。换算 `Ztop = 63 − y`、`Ydepth = 32 − z`。报告里的 `X/Ztop/Ydepth` 一律是量测书口径。
2. **r1 的教训**：正面图上方 71px 不是正脸上沿，而是**顶面在俯视下的投影**。正脸纵向比例要用镜圈椭圆反解（Ø28.9 横 / 208px 纵 ⇒ 7.20px/mm），不要拿机身外接框直接除 63。
3. **丝印必须走 MASK 贴花**：RGB 烘焙底色的不透明平板在 three.js（网页同栈）里会露矩形并 z-fighting；本轮已全部改 RGBA + alphaMode=MASK + 沿法线抬 0.07（顶面 0.12）。
4. **端面朝向**：+X 端（远离握把）是**香槟**（`IMG_165552`：OPEN 滑钮 + Ø12 电池门 + 竖分模线）；−X 端（握把）是**全黑 + 黑圆顶 + 三节铰链 + 2 螺丝**（`IMG_165644`）。量测书旧版 E3/E4 曾经写反，已由 lead 更正。
5. **顶面黑肩**：照片 3.2–7.9（官方 top）/ 7.2（`IMG_165536`）；旧 spec 写 13，已改 7。
6. **验收复测法**（可复现）：`.tmp/bm21rev/` 下的 three.js 正交渲染器（headless Chrome，ACES+RoomEnvironment，1200×760，ppm 11.3）+ `probe.mjs` 逐节点 Box3 反解。腰线复测：`front.png` 行 y262–668、从 x=390 向左扫到 lum<120。
