## 1. P0（不修不签收）

### P0-1 顶面/背面黑端盖过宽——顶面被吃掉 1/5
- 实测（`bm21-top.png`）：顶面黑盖只到 **x≈4.6–7.9**（y=392 行 923–951 为香槟、952 起才是黑；y=300 行黑区 905–974 = 7.3mm）；正面黑盖边界 17.8–22.9（见 P0-2）。
- 模型：`Grip x[0.3,20.8]` 一个件盖住正/顶/底/侧，**顶面黑区 18.8mm**（v3-front 量 19.0）。
- 后果：**快门（x 6.0–19.6）整颗落在黑盖上**；实物快门在香槟面上，距黑盖 3.0mm（top 图 923–951 = 3.0mm 香槟间隔）。
- 改：顶面黑盖边界做曲线——前缘≈8.0、中段≈3.5、后缘≈5.0；快门中心 x=13.9、Ø12.6，**四周留香槟**，与黑盖留 3.0 缝。

### P0-2 正面握把分模线是直线，实物是腰形曲线
- 实测（`bm21-front.png` 逐行 first_silver_x）：x(y) = **22.9@y52.8 → 21.1@47.8 → 19.7@42.8 → 18.1@32.8 → 17.8@y30（最窄）→ 18.4@17.8 → 19.3@12.8 → 20.6@7.8 → 21.5@5.3**。
- 模型：`Grip` 正面边界是 x=20.8 的**竖直直线**，顶/底不 flare。
- 改：正面缝线按上表做样条（腰 17.8 @ y=30，两端 22.9 / 21.5），并让缝线绕到顶面（→8.0/3.5/5.0）与底面。

### P0-3 正面黑色前额面板（VF+AF+闪光）整体高 7.3mm
- 实测：面板 **y 39.3–52.7（高 13.4）**，机顶到面板顶缘 **10.3mm**（161−79=82px）。
- 模型 `FrontStrip`: **y 43.0–60.0（高 17.0）**，距机顶只有 2.3mm。
- 改：面板整体下移，顶缘 52.7（−7.3）、底缘 39.3（−3.7）、高度 13.4（−3.6）；x 30.8–96.5 保持（实测 29.6–97.3 ✓）。

### P0-4 正面丝印整块大 1.8–2×，且向 +X（握把端）偏 9–10mm
从 GLB 的 `front_logo` 贴图直接量字（mm，模型坐标系）：

### P0-5 顶面多印了 “Konica”；三行块也大了 1.5×
- 实测顶面只有三行：**big mini / RED EYE REDUCTION / AUTO FOCUS BM-21**，整块 **16.6mm 宽 × 4.9mm 高**，x 74.9–91.5（`bm21-top.png` 115–275 / 348–395），与 `IMG_165536`、`IMG_165658`、`IMG_165716` 一致。
- 模型：`TopPrint` 40×20mm 的贴花，内含 **“Konica” 19.2×6.6 @ x 74.0–93.3, y 55.4–62.0** + 三行块 16.2×7.27 @ 77.4–93.6 → **多一行、且大到压住整个顶面右半**。
- 改：删掉顶面 Konica；三行块按 x 74.9–91.5 / 总高 4.9 重排；另补 **C:AF 两个指示**：空心环 **Ø4.4 @ x 62.5–66.9**、实心点 **Ø2.5 @ x 62.5–65.0**（模型现在把两个 Ø1.7 孔放到了 x 36.9–41.4，位置全错）。

### P0-6 丝印实现方式：不透明烘焙底色 + 4 处共面 z-fighting
- 5 张丝印贴图全是 **RGB 无 alpha（alpha min=max=255）**，`alphaMode` 缺省 OPAQUE，底色被烘焙进图（front_logo 底 208、back_print 底 237）→ 换光照就露矩形。
- **完全共面**：`TopPrint y=62.0` = 壳顶 62.0；`BottomPrint y=0.0` = 壳底 0.0；`BackPrint z=2.0` = 后盖外表面 2.0；`SelectSet y=62.0`。
- 我在 three.js（ACES＋RoomEnvironment，与网页同栈）里直接看到：顶面一整块**比机身亮一档的矩形**、背面 “Konica FILM” 坐在一块**深一档的黑矩形**里。
- 改：① PNG 存 RGBA，背景全透明；② `alphaMode=BLEND`（或 `MASK`+cutoff 0.35）；③ 贴花沿法线抬 **0.03–0.05mm**；④ 底色不要烘焙，靠材质自身。

## 3. P2（可不拦签收）

1. **快门外圈** ShutterRing Ø18.4 香槟环太显眼；实拍只是 Ø12.6 黑钮 + 极细台阶（≤16）。
2. **镜圈外亮台阶** LensBezel Ø35.1 → 照片上黑环外的亮环很窄，建议 **Ø31.5**。
3. **镜圈弧字偏小**：照片字高 ≈1.6mm（`front-lens` 特写），模型约 1.0mm。
4. **背面小点** BackLamp (38.0–41.1, 47.3–50.4) → 实测 (34.7–37.7, 52.1–55.1) Ø3.0。
5. **底面螺丝** 2 颗 ✓ Ø2.7 ✓，间距 48.0（实测 46.6），整体 −X 5.5。
6. **闪光棱条** 15 条（FlashRib0–14）→ 实拍约 9–10 条，条宽偏细。
7. **取景窗** FinderWindow 12.6×11.3 @ x45.0–57.5 → 实测约 10.8 宽、中心 x 48.6。
8. 机身上下圆角：模型四角 R 偏小（照片立边更圆，R≈5–6），不影响识别。

## 4. 给作者的最小修改顺序（照这个顺序做，别一次全改）

1. **先修 P0-6（贴花技术）**：否则后面每改一次丝印都要重导一次 PNG，白做。
2. **P0-1 + P0-2（黑端盖曲面）**：一个件决定正面+顶面+底面三个面的缝线，改完顶面快门位置才有意义。
3. **P0-3（正面面板下移 7.3mm）**：VF/AF/闪光三个件都要跟着下移，先移面板再放件。
4. **P0-4 / P0-5（丝印按表重排）**：字号先对，位置再对。
5. 然后 P1 表按 X/Y 数字批量挪。

## 5. 一句话

> 形体的“骨架”是对的（100×63×32、镜筒 Ø29.8 与位置、香槟材质参数全对），但**黑色握把在顶面宽了 3–5 倍、正面那条该有的腰形曲线是直线、正面丝印大到 1.8–2 倍且整体挪了 1cm、顶面还多印了一个 Konica**——现在读起来像“BM-21 的简化玩具版”，不是 1:1 复原。
