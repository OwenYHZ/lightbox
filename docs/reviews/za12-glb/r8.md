## 2. P1

### P1-1 拨盘超出银色机身（每侧 ≈1.5mm）

**证据（官方侧）**
- p2 正视（55mm=499px=9.073px/mm）：左盘亮轮廓左缘 **x=97**，机身左缘 **x=93** → 盘在机身内 **0.4mm**；右盘右缘 **x=584**，机身右缘 **x=592** → 盘在机身内 **0.9mm**。
- 结论：**官方正视里两盘都在 55mm 宽度之内**，"超出"只发生在黑色顶盖，不在机身。

**证据（本版）**
- `DialLeft` X 3.00…29.00 → 外缘 **±29.0**，机身半宽 27.5 → **每侧出 1.5mm**。
- front.png：整机轮廓宽实测 **459px / 8.345 = 58.9mm**（机身仍是 55）→ **正视剪影变宽 3.9mm**。
- bottom.png：第 450–500 行轮廓伸到 x=152…606，比机身（166…592）**每侧多 1.8mm**——从正下方能看到两个盘探出机身外（真实机器不会）。

**改（保持用户"大拨盘 + 指示灯 4.4"两个诉求同时成立）**
- `DIAL_R = 12.0`（Ø24.0）、`DIAL_X = 15.2`（中心距 **30.4**）→ 外缘 **±27.2**（机身内 0.3、**顶盖外 0.9** ✓ 仍是"微微超过顶盖"）
- 两盘净空 = 30.4 − 24.0 = **6.4mm**，容 4.4 槽 + 两侧各 1.0 ✓
- 齿数按齿距 0.42 → **180**
- 若坚持 Ø26：数值上无解（26×2 + 4.4 + 2×0.8 = 58 > 顶盖 52.6，必然出机身），只能牺牲槽宽或出边。

## 3. 裁决

### A. 顶盖齐平（PLATE_SINK 0）与拨盘露出 1.1 —— **按 1.1 交付**

- 用户最新一条要"顶盖与壳顶齐平" → PLATE_SINK=0 ✓ 正确。
- "顶盖比拨盘面低 0.3"是更早一条的口径；若照做，滚花环只剩 0.3 高，与"滚花环高 1–1.5mm"直接冲突。
- **取拨盘露出 1.10–1.40**（你 1.10 合格，建议 1.25 取中），并在交接里写明"顶面比拨盘面低 1.1–1.4"这一最终口径。

### B. 拨盘出机身 —— **不采纳**（见 P1-1）

用户"微微超过"是对**黑色顶盖**说的（顶盖半宽 26.3），不是机身（27.5）。P1-1 给的 Ø24/X15.2 同时满足"比顶盖大 0.9"和"不出机身"。

### C. 拨盘字向 —— **保持现状**

盘是旋钮，转角任意；p1 的 12 点位只是出厂状态。不必再转，避免又一轮 churn。

## 6. 20:00 追加裁决（拨盘字向）

lead 转达"p1 里每个数字基线水平（正立）"，与实测不符，**不采纳**。证据：`evidence/p1-vs-model-dial-orientation.png`（左=官方 p1 右盘 / 右=模型 v6 ISO 盘）。

**p1 实测字形倾角**（水平=0°）

| 数字 | 角位 | 倾角 | 说明 |
|---|---|---|---|
| 50 | ~11 点 | ≈ −25° | 斜 |
| **200** | **9 点** | **≈ 0°** | 9 点位半径方向正好水平 |
| 100 | ~10 点 | ≈ −45° | |
| 400 | ~8 点 | ≈ +30° | |
| 800 | ~7 点 | ≈ +60° | |
| **1600** | **6 点** | **≈ 90°** | 6 点位半径方向正好竖直（p1 上是倒竖的） |

→ **规则 = 字符串沿半径排（径向），每个字按自己的角位旋转**；不存在"基线水平"。

**模型现状 = 切向**：同一个 9 点位，p1 的 "200" 水平、模型的 "200" 竖直 → **系统差 90°**。这才是"看着不对"的根因。

**r9 验收口径**：`rotate = 角位`（径向）。在 `top-p1` 与 p1 并排核：9 点位数字水平、6 点位数字竖直、11 点位 ≈ −25°。
若用户坚持"正立"，按"依用户、偏离官方"记录进交接，并需用户明确确认一次。
