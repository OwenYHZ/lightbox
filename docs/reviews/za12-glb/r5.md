**几何复核（.blend / ray-cast）**：Shell 已开 Ø5.0 沉台；SensorRim Ø5.0（Y −23.42…−22.87）、SensorGlass Ø2.72（Y −23.32）、SensorHole Ø2.76（Y −23.16 之后）。射线 x=17.7/18.4 命中 SensorGlass，x=19.2/20.0 命中 SensorRim → **环已露在外壳外面 ✓**，r4 的阻塞项解除。
