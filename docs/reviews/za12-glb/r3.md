## 4. P2 打磨清单（不拦签收）

1. **ZA12 印刷面像贴纸**（你自己标的问题 2，我确认成立）：贴图底总亮度 ≈0.25，座面 ≈0.10，中间有一条明暗分界的矩形。**贴图底压到 0.02**（或把字烘进座面贴图、plane 直接删掉）。
2. **窗框内沿高光偏强**（问题 1，部分成立）：框壁内倒角有一圈 3–4px 全白晕，官方是"细暗缝 + 细亮边"。框壁 roughness 0.42→0.60、内倒角 0.35→0.20 即可，不必改结构。
3. **盘根环缝偏窄**（问题 3，成立）：库存里 `DialGroove` 已存在（z 23.30–23.56），但 top.png 里暗环只有 ~1px（0.13mm）；量测书 §7.2 要 0.25。把环缝内径各放 0.12 即可。
4. **底面认证块被热靴压字**：bottom.png 里 "CE / UKCA / FC Ⅲ" 行被热靴方块切掉半个 CE，"Input: …" 也被分成两段；p3 底面是整块丝印排在热靴右侧。认证块右移 4mm 或整体缩到 0.9 字号。
5. **底视图下缘有一块来历不明的浅灰凸片**：世界坐标约 **Y≈+22、X=±4.9、凸出底面 0.8mm**（bottom.png 下缘居中 75×6px）。不在任何官方图里，请确认它是哪个对象（`ShoeLabel` 若被放到 Y=+22 就是它）。
6. **背面按键竖向仍低 1.3mm**：back.png 图标心 424.5 vs 银壳中线 ~412 → `BTN_Z` 12.5 → 13.8（p5 居中）。
7. **热靴三段台阶**：mount 21 / foot 19 / tongue 17.6 三层，back.png 仍读作"婚礼蛋糕"；p5 是一整块黑座 + 底部金属导轨。foot 与 tongue 并成一段、只留 1 处 0.5 台阶。
