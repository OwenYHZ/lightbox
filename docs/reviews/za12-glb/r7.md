## 4. 交接备注（P2，不拦上线）

1. **顶板底色**：本版顶视 ≈#2f3235，官方 p1 ≈#1a1e20（贴图底再压一档）。
2. **盘面基色**：≈0.66，p1 是浅灰铝 ≈0.58。
3. **底面认证块**："CE / UKCA / FC Ⅲ" 行左端仍被热靴切到半个 CE → 右移 4mm。
4. **窗内菲涅尔**：左半窗环纹对比偏低（≈2%），PERIOD 1.2→1.35 可让左侧环弧更疏。
5. **已知偏差（已接受）**：顶盖四边留边 1.9（官方 1.0–1.3）——受盘外缘 26.7 / 机身 27.5 / 中心距 30.4 / 槽 6.2 的算术约束，取 1.9 是可行解。
6. **glTF 不带 anisotropy**（KHR_materials_anisotropy 默认不导出），网页里银壳比 Blender 略平。
7. **文档待修**：`docs/za12-spec.md` §3.3 T3/T4/T10 前后关系与实物相反（盘在后、ZENIKO 在前）、§3.1 F6 电眼 Ø4.6→Ø5.0（环宽 1.0）、T3 拨盘 Ø16→Ø23（DIAL_X 15.2 / 中心距 30.4 / 距后缘 11.8）。
