## 2. P1（拦签收）

### P1-1 窗框外框四角黑楔

- **现象**：detail/window.png（≈42px/mm）里窗口外框的**四个外侧角各有一块 ≈25px≈0.6mm 的黑色三角楔**，是暗腔从框角漏出来；front.png（760px）里也能看到 4 个深色角点。
- **几何**：`WinFrameLiner` X −17.00…12.60（29.6 宽）/ Z 9.25…19.75（10.5 高）/ Y −23.50…−22.50；沉台 29.1×10.0 R2.6。内衬比沉台每边大 0.25 ✓，但**角部圆角没有跟着做等距偏移**，所以四条直边盖住了、四个角没盖住。
- **修**：内衬用与沉台同一个 `rounded_points` 剖面生成，尺寸 = 沉台 + 0.25 等距（含圆角 R 同步 2.6→2.85、圆心不动），或把内衬角半径直接改成 2.85 并确认四角覆盖。
- **验收**：detail/window.png 四个外角无黑色三角，框壁连续。

### P1-2 盘面刻度字偏小偏窄

- **口径**（字符串长 / 盘径，避开 cap 的口径争议）：
  - p1 右盘 "1600"/"800" 串长 ≈ **0.21–0.23 Ø**（p1_dialR 原图 4× 放大核过，字粗、字距大）；
  - 本版渲染 ≈ **0.14–0.17 Ø**（top.png 右盘 Ø210px，"1600" ≈32–36px）。
  - → **偏小 25–35%**。
- 原因不是 cap（你的 2.88mm = 0.125×Ø 其实比 p1 的 0.113 还大），而是**字宽太窄**：p1 每字宽 ≈0.38×cap，你现在 ≈0.22×cap（scaleX 0.55 再乘窄体底字）。
- **修**：把刻度层的横向比例 **scaleX 0.55 → 0.72–0.75**（cap 维持 2.88），串长即到 0.20–0.21 Ø；左盘 6 个刻度仍有 2.9mm 步长可容（0.72×0.556em×2.88 ≈ 1.15mm/字，"5.6" ≈2.6mm < 2.9mm）。
- **验收**：top.png 右盘 "1600" 串长 ≥0.19 Ø，左盘 "5.6" ≥0.155 Ø。

## 3. 裁决 / 更正

### A. 右盘环层次：**已满足 ✓（用户要求 = p1 事实 = 现状）**

- 用户的要求是"50~1600 的 ISO 数字靠外侧，不在内侧"。
- p1 放大 4× 逐环核过：**黑色 ISO（50/100/200✦/400/800/1600）在外圈（≈0.75–0.80R），红色快门（−1/64…−FULL）在内圈（≈0.62–0.68R）**。
- 本版实测 **ISO 0.77R / 红快门 0.68R** → **与 p1 一致、与用户要求一致，✓ 关闭**。
- 需要更正的是**我自己**：r1 §2 曾写成"外环红、内环黑"，与 p1 相反，此处作废。

### B. 顶盖留边 1.9mm：接受你的取舍

p1 实测四边 1.0–1.3，但按你的算术（盘外缘 26.7 已到机身 27.5 内 0.8、中心距 30.4、槽 6.2），留边做到 1.3 会把盘顶出机身或让两盘间塞不下槽。**接受 1.9（实测 2.0–2.2）**，这条记为"已知偏差"进交接备注，不再改。

### C. 顶棱 0.12：按用户，但提醒实物

p3/222313 的实物顶棱有 ≈R1 的柔边（高光带宽 ≈0.8–1.2mm），0.12 破边在近景会读成"刀切"。既然用户明确要"利"，**按 0.12 交付**；若后续觉得过硬，**R0.6** 是两全值。
