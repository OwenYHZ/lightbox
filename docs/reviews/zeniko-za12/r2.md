## ② 争议裁决（ZA12 深度）

**方向采纳作者，数值仍偏浅一档；我 r1 的 0.73 撤回。**
- 作者论点正确：拨盘 Ø0.684 要落在顶板上、ZENIKO 字带要留位，D 不可能只有 0.41 W。r1 我用的是 222313 侧面"高:深"目测，被透视缩短带偏，撤回。
- 我的独立量取（底面 222234，1100 px 网格裁切，缩放 0.640）：黑面板 **825 × 665 px** → **W : D = 1.24 → D = 0.806 W**；
  交叉验证（鞋轨）：鞋块 0.29 W ↔ 标准热靴宽 18.5 mm、鞋长 0.49 D ↔ 22 mm ⇒ **D/W ≈ 0.70–0.75**。
- 结论：**D/W ≈ 0.75 ± 0.05 → W = 1.8 时 D = 1.35 ± 0.09**；现 1.20（0.667 W）比下限还浅 ~11%。
- 建议：`const D = 1.20 → 1.32`（P2，不影响正面轮廓，只影响 3/4 视角的厚重感）。

## ③ 新引入的问题

1. **P1 柔光窗过曝成一条白杠**
   - 照片 222229/222313：灰白柔光片，能看清内部 7 条棱与灯管
   - 渲染：玻璃后面的灯管（`m.frosted 0xe8e5dc`）在强光下直接过曝，把 7 条棱吃掉
   - 改法：灯管 `m.frosted` → 自定义 `MeshStandardMaterial(color 0xcfd2d0, roughness 0.9)`；`m.glassClear` 副本 `opacity 0.34 → 0.26`；棱条改 0xc2c7cb（现在是 m.silver，反光过强）
2. **P1 拨盘刻度不足**
   - 照片 222217：左盘 f/2 · 2.8 · 4 · 5.6 · 8 · 11（含黑三角指针、f/stop 铭），右盘外圈 -1/64…-1/2 · FULL、内圈 50 · 100 · 200 · 400 · 800 · 1600 ISO
   - 实现：只有两条整串 label（`f/stop`、`50 100 400 1600`）贴在顶板上，不在盘缘
   - 改法：改成逐值 label（左 6 个、右外 7 个、右内 7 个），沿 r = 0.29 每 30° 摆一个，rotation 按切向；字高 0.028
3. P2 ZENIKO 丝印在顶板 **z = +0.30（靠前）**，而 222330 / 222313 显示应靠后 → 建议 `z = -0.25`，拨盘 `DIAL_Z -0.18 → +0.10` 对调（存疑项，需以 222330 再确认一次）。
4. P2 顶板圆形凹槽（`TorusGeometry(DIAL_R*1.08)`）在渲染里被拨盘挡住，看不出效果，可删。
5. P2 SVG 两串刻度字目前挤在盘的顶弧上（font-size 3.5），480 px 卡面上几乎不可读；建议只保留 3 个代表值（2 · 5.6 · 11）。

## ④ 跨件共用材质（与 olympus r2 §4 同一处）

银面中位亮度：渲染 **0.843** vs 照片 **0.447**（+0.40，约 +0.9 EV），三件里偏亮最严重的一件——因为 ZA12 实物是哑光拉丝铝，不应该和 BM-21 的亮铝同一个 `m.silver`。
建议：`m.silver` 全局按 olympus r2 §4 调暗后，ZA12 再单独 `silver.roughness += 0.08`、`envMapIntensity -= 0.1`（模型内克隆材质，不动共用定义）。
