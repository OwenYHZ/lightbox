## 三、P0 返工清单

1. **P0-1 正面上下比例不对（用户原话）**
   - 照片依据：222229 机身 915 × 398 px = **2.30 : 1**。
   - 当前实现：SVG 262×131 = 2.00、3D 1.80×0.91 = 1.98，都矮胖了 13%。
   - 改法：SVG B 246 → **229**（高 114）；3D SHELL_H 0.78 → **0.69**、BASE_H 0.13 → **0.09**。
2. **P0-2 颜色不对（用户原话）**
   - 照片依据：222229 / 222313 银拉丝铝机身 + 黑顶板 + 黑底带。
   - 当前实现：`src/data/gear.js:885` 给了 `tone:"graphite"`，而模型银件全用 `m.plate`，graphite 下是 0x363b44 蓝灰 → 整机渲染成炭黑。
   - 改法：`tone: "silver"`；模型里银色件（shell / dial / frontBand / shoePlate 边）改 `m.silver`（0xd8dade），只有顶板/底带/热靴用 `m.rubber`/`m.dark`。
3. **P0-3 灯面不透（用户原话「玻璃/灯面不透」）**
   - 照片依据：222229 柔光窗是灰白棱纹柔光片，能看见内部灯管。
   - 当前实现：`diffuser` = `m.frosted`（不透明奶白，metalness 0.06），无棱纹，渲染成白色卡片。
   - 改法：换 `m.glassClear`（opacity 0.4）+ 7 条 0.008 浅灰棱 + 一根 r0.05 灯管。
4. **P0-4 热靴在左下，不是居中/右下（用户原话）**
   - 照片依据：222229 热靴 x 0.191–0.530 W，中心 0.36 W。
   - 当前实现：SVG 0.33–0.60 W；3D 完全居中（x = 0），宽 0.34 = 0.19 W（照片 0.34 W）。
   - 改法：SVG x 159 / w 89；3D `foot.position.x = -0.25`、宽 0.61。
5. **P0-5 一件文字都没有（用户原话「没有文字」）**
   - 照片依据：顶板 ZENIKO；两拨盘 2/2.8/4/5.6/8/11、-1/64…FULL、50…1600 ISO、f/stop；底带 ZA12。
   - 当前实现：3D `helpers.label` 0 次；SVG 只有一个跑出机身外的 ZA12。
   - 改法：见 #11 的三处 label；矢量把 ZA12 收回底带内（y 224、6px），并给两拨盘加 3–4 个刻度数字（font-size 3.5）。

## 四、P1 汇总（11 条）

顶板内缩 0.81→0.96；底带 0.9→0.99；柔光窗高 0.21H→0.29H 且下移；测光孔 Ø 0.042→0.085 W；
