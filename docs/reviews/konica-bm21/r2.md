## ③ 新引入的问题

**P0-N1 三维顶部那一排窗口整体左移 + 缩小（30% 黑面空着）**
- 照片（165526）：AF 0.318–0.429 / 取景 0.430–0.580 / 小窗 0.580–0.640 / 闪光 0.700–0.920 W
- 渲染实测（`konica-3d-front.png` y=345 扫描）：AF **0.284–0.335** / 取景 **0.377–0.478** / 小窗 **0.493–0.525** / 闪光 **0.571–0.704**
- 后果：条带 0.70–1.00 全是空黑面，正好是用户"取景器那一排一团糟"的原点；而且闪光窗宽度只有照片的 61%
- 改法（`src/lib/three/models/konica-bm21.js`）：
  - AF：`relX(0.32)` → **`relX(0.373)`**；`afCavity 0.15` → **0.211**
  - 取景：`relX(0.432)` → **`relX(0.505)`**；`rectFrame(0.217,0.194)` → **(0.285, 0.185)**
  - 小圆窗：`relX(0.5115)` → **`relX(0.610)`**
  - 闪光：`relX(0.635)` → **`relX(0.810)`**；`rectFrame(0.276,0.186)` → **(0.418, 0.185)**；玻璃 0.25→**0.38**；棱条跨度同步到 ±0.16
- 注：矢量这边是对的（0.317–0.428 / 0.431–0.579 / 0.610 / 0.700–0.879），只有三维错。
