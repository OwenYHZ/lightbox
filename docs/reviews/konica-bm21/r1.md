## 三、P0 返工清单（按此顺序做）

1. **P0-1 握把内缘弧线方向反了、也太宽**（矢量）
   - 照片依据：165526 左端黑带内缘 上 0.185 W / 中 0.158 W / 下 0.175 W —— 中间是**收进去**的。
   - 当前实现：`M152 93 Q178 200 150 271`，控制点 178 把曲线往右推，中部鼓到 0.24 W。
   - 改法：`M149 93 Q141 182 146 271`；副线 `M150 100 Q137 190 144 264`。
2. **P0-2 镜头组整体偏高 0.10 H**（矢量 + 三维）
   - 照片依据：165526 圆心在 0.620 H，外圈下缘 0.94 H 几乎贴底。
   - 当前实现：SVG cy=186（0.522 H）；3D `relY(0.522)`。
   - 改法：SVG cy → **203**；3D `lens.position.set(relX(0.459), relY(0.62), 0)`。
3. **P0-3 窗玻璃不透明**（三维）
   - 照片依据：165526 AF 窗/取景窗透见内部，闪光窗为乳白透光棱面。
   - 当前实现：`afGlass/ vfGlass / flGlass 全部 materials.glass`（0x05080c、metalness 0.88）。
   - 改法：三处换 `m.glassClear`；闪光棱条 `m.dark` → 0xe9eef2、宽 0.006。
4. **P0-4 正面没有文字**（三维 0 处；矢量字号减半且缺镜圈字）
   - 照片依据：165526 Konica（0.817 W / 0.37 H / 字高 0.081 H）、big mini（0.53 H / 0.067 H）、RED EYE REDUCTION 与 AUTO FOCUS BM-21（0.63–0.69 H）、镜圈两段弧形白字 F4.5。
   - 当前实现：3D 未调用 `helpers.label`；SVG 只有 8px/7px 两行，镜圈只有线没字。
   - 改法：3D 五处 `label`：Konica height 0.094 @ (0.60, 0.44)、big mini 0.078 @ (0.58, 0.60)、RED EYE REDUCTION 0.026 @ (0.585, 0.665)、AUTO FOCUS BM-21 0.026 @ (0.585, 0.70)、背面 Konica FILM 0.05 @ (0.5, 0.28)；SVG 见 #16 / #17。
5. **P0-5 给傻瓜机镜筒和快门钮加了滚花（齿轮）**（三维）
   - 照片依据：165526、165658 镜筒是光滑金属环，快门钮无齿。
   - 当前实现：`knurlRing(0.336, 72, [0.008,0.008,0.05], m.plate, FRONT+0.06)` 与 `knurlRing(0.142, 32, …)`。
   - 改法：两行删除。
6. **P0-6 矢量里没有任何黑色块面**（矢量）
   - 照片依据：165526 黑握把 + 顶条 + 快门盖是实心磨砂黑。
   - 当前实现：整张 SVG 只有描边，黑区靠两三根线暗示。
   - 改法：三块黑区各加一组 45° 排线（间距 3.5、stroke-opacity 0.12），顶条加 fill-opacity 0.06 底。

## 四、P1 汇总（11 条）

厚度 0.54→0.61；顶条高 134→141；镜头外圈 rOut 51→57 / 3D 0.334→0.375；黑筒 r→46 / 0.304；
快门盖改竖长 45×51；AF 窗改圆角方腔；3D 取景窗去掉亮银梁；3D 补 2×3 圆点；
顶面按钮改黑塑料并加 MODE/ON 字；背面补 Konica FILM + ISO 贴纸并把 eyeBump 收到 0.23；前面板去台阶；
另 P1：删掉多余 `rearCap`。

## 五、一句话

骨架对了，但"黑色是空的、文字是没有的、镜头是飘高的、镜筒长了齿轮"——四条全踩在用户雷点上；
把 P0-1…6 修完，磨砂银 + 黑胶的双色质感才能立住。
